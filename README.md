# 🦾 Prosthetic Robotic Arm

> Prosthetic robotic arm for amputees, activated by nerve signals above the elbow.

## 📖 Overview

A prosthetic robotic arm designed to help people who have lost an arm. The arm is **activated using signals from the nerve above the elbow**, letting the user control it more naturally.

## ❓ Problem

Many prosthetics are purely cosmetic or expensive. An affordable, signal-controlled arm can restore useful movement and independence.

## ✨ Key Features

- Activated by biological signals from above the elbow
- Robotic hand/arm movement controlled by the user
- Focus on affordability and accessibility
- Iterative testing and debugging of the control system

## ⚙️ How It Works

1. Electrodes pick up signals from the nerve/muscle above the elbow
2. Signals are amplified and filtered
3. The controller interprets the signal and decides the movement
4. Actuators move the robotic arm accordingly
